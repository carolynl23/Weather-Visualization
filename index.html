Daily Temperatures in the U.S.

Intro of Dataset

This project visualizes daily weather patterns across the contiguous United States (excluding Alaska and Hawaii) in 2017 using station-based meteorological data from the “Daily Weather in the U.S., 2017” provided by the NOAA Daily Global Historical Climatology Network.

The dataset contains daily observations recorded at weather stations across the country, including station metadata (station name, state, latitude, and longitude) and weather variables, such as the average temperature (TAVG), minimum temperature (TMIN), maximum temperature (TMAX), precipitation (PRCP), snowfall (SNOW), and wind speed (AWND). For this visualization, we primarily focused on the average daily temperature (TAVG) as the main encoded variable because it provides a balanced summary of daily conditions while also being intuitive to interpret and visually display. When TAVG values were unavailable for a particular data point, but TMIN and TMAX were present, we approximated the average using the midpoint of these values to reduce missing data.

The design of this visualization was guided by the geographic and temporal structure of the dataset. Because the data consists of weather observations recorded at specific physical locations, a projected map of the continental United States was chosen as the primary view to preserve spatial accuracy and allow users to recognize regional patterns immediately. Instead of plotting latitude and longitude on raw axes, we used the Albers USA projection to align stations with state boundaries, improving interpretability. Station location is encoded by position, while average temperature is encoded using a red–yellow–blue color scale, with cooler temperatures shown in blue and warmer temperatures in red. Color was selected as the primary encoding because it enables intuitive comparison across many spatial points without cluttering the map. A percentile-based domain was used to enhance contrast among common temperature values and reduce the influence of extreme outliers. To support interaction, a timeline slider provides dynamic filtering by date, allowing users to explore seasonal change across the year, while zoom and pan enable multi-scale spatial exploration. Details-on-demand are implemented through hover tooltips that reveal station name, location, and daily weather values, preserving a clean visual surface while still allowing deeper inspection. Hover tooltips let users see the station name, location, and daily weather values without cluttering the map, so the main view stays clean but still informative. We considered other options like a state-level choropleth map and a simple latitude–longitude scatterplot, but those either hid station-level detail or didn’t provide enough geographic context. Small-multiple monthly views were also explored, but they didn’t allow for the same smooth, interactive time exploration as the slider. Overall, the final design keeps the map clear and accurate while still making it easy and engaging to explore the data.
